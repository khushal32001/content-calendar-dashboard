# Kaapi Culture Workspace

A modern and interactive content calendar dashboard built using HTML, CSS, and JavaScript. This project helps digital marketers plan, organize, and monitor social media content across multiple platforms.

## Overview

Kaapi Culture Workspace is designed for managing a monthly content strategy with an easy-to-use interface. It includes a content calendar, strategy overview, KPI tracking, and search/filter functionality.

## Features

- Responsive dashboard layout
- Strategy and roadmap section
- Interactive content calendar
- KPI tracking dashboard
- Platform-based content filtering
- Search functionality
- Modern UI design
- Pure HTML, CSS, and JavaScript
- No external frameworks required

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts
